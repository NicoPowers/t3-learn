# t3-learn

A local web app for learning any subject through conversation with a private AI tutor. T3 Code runs the tutor in the background.

Status: planning. Read [PLAN.md](PLAN.md) for the full plan.

The upstream project this builds on is copied into `reference/learn`, which git does not track. To restore it:

```sh
git clone https://github.com/amosblomqvist/learn.git reference/learn
```
